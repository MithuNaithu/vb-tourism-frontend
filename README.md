# Visit Valiyaparamba 🌴🚤

A full-stack tourism platform showcasing the beauty of Valiyaparamba Backwaters in Kasaragod, Kerala. 

This project serves as a digital bridge connecting travelers with authentic local experiences, managing enquiries for houseboat cruises and homestays.

---

## 🌍 About Valiyaparamba

Valiyaparamba is one of the most beautiful and peaceful backwater destinations in northern Kerala. It is located in the Kavvayi Kayal backwater system formed by the Tejaswini (Kariangode) River.

The region features a long island of approximately 24 km, surrounded by backwaters on one side and the Arabian Sea on the other. It is a unique destination where visitors can experience both serene backwaters and pristine beaches in one place.

---

## ✨ Features

- **Dynamic Frontend:** Fast, responsive UI built with React and Vite.
- **Automated Enquiries:** Custom form that captures lead data and instantly redirects users to WhatsApp for seamless communication.
- **Secure Admin Panel:** A dedicated dashboard to view, manage, and delete customer leads.
- **Live Visitor Tracking:** Real-time visitor counter integrated via external API.
- **Database Integration:** Secure storage of all customer interactions using MongoDB.

---

## 🛠 Technologies Used

**Frontend:**
- React.js (Powered by Vite for fast compilation)
- Bootstrap 5 & Custom CSS
- React Router (Client-side routing)

**Backend:**
- Node.js & Express.js
- MongoDB & Mongoose
- RESTful API Architecture
